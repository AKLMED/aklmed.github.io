v0.2.3​

更新时间：2026/8/7

  • 禁用传送门运输生物功能（暂时）
  • 试运行电费系统（不收取费用）
    • 岛屿等级大于50级则开始收费
    • 每月免费1200度电
    • 岛屿mspt大于50时每分钟按每度电收取50金币，输入/ie查看岛屿电费情况
    • 欠费将停用岛屿生物AI和生成机制直至成功缴纳电费
  • 固定收购商店新增几种商品
  • 固定收购商店现在不再刷新次数限制
  • 新增随机收购商人归舟，可在主城找到，其收购价较高，每日轮换并刷新次数限制。
  • 现在特殊结构中，结构特有生物大于10只将不再生成
  • 现在使用鞍搬运生物时会取消玩家右键交互行为
  • 优化服务器性能
  • 修复广告位的一些 BUG
  • 修复在特殊结构下生物会在不完整方块下生成的 BUG
  • 修复某些情况下在永久合作成员选项开启时合作成员离线后仍会取消其权限的 BUG
  • 修复邀请玩家加入岛屿时消息提示错误显示的 BUG
  • 修复无法搬运村民、游商等生物的 BUG

v0.2.2​

更新时间：2026/8/4

  • 加入生物搬运机制，主命令/piggy
    手持鞍右键生物即可抱起、左键或Q键丢出生物（会造成对其伤害）
    不可被抱起的生物：
    • 凋灵、末影龙、监守者
    • 末影螨、凋灵骷髅、远古守卫者、潜影贝、蠹虫、恶魂、岩浆怪
    • 唤魔者、卫道士、掠夺者、幻术师、女巫、劫掠兽、猪灵蛮兵
    • 铁傀儡、巨人、疣猪兽、僵尸疣猪兽、骆驼、嗅探兽
    • 鳕鱼、鲑鱼、河豚、热带鱼、海豚、鱿鱼、荧光鱿鱼、海龟、守卫者
    • 鹦鹉、蝙蝠、幻翼、恼鬼、悦灵
    • 旋风人、嘎枝、沼骸
    • 猪灵、僵尸猪灵
  • 加入多种机制
  • 现在只有下界生物才能穿戴下界合金盔甲
