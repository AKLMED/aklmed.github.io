# 岛屿价值
:::info
岛屿等级的具体计算方式及相关参数属于服务器内部实现，可能会根据版本更新或平衡性调整而发生变化，因此本文仅介绍其基本原理，而不提供详细计算公式。
:::
岛屿价值于衡量岛屿的整体建设水平，是岛屿等级计算的重要依据。岛屿价值由方块价值决定。

等级计算采用了**分段价值映射模型**，并会结合岛屿当前的发展阶段进行调整。因此，岛屿等级与综合价值并不是简单的线性关系，随着等级逐渐提高，相同的价值增量所带来的等级提升也会逐渐减少。

此外，不同发展阶段使用的计算参数并不完全相同，因此不能直接将不同阶段的岛屿等级进行横向比较。
