# Q:金币有什么用？怎么获得？

A:用于升级岛屿`/is upgrade`或者用于商店购买物品   
金币获取途径：
1. 出售多余的物资，你需要渠道主城，如果你觉得太麻烦，你可以输入`/sethome`在旁边设置一个传送点
2. 完成任务可以获得大量金币`/task`
3. 签到奖励`/signin gui`
4. 向其他玩家出售物品   
你可以创建一个箱子商店：放置一个箱子、持有需要出售的物品左键箱子，然后按照步骤完成创建就行了  
Q:该怎么让其他玩家知道我的商店？  
  A:你可以在主菜单买一个广告位，这样其他玩家就可以看见了`/cd`
