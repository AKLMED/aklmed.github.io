# 岛屿生物群系

玩家可以查看并更改自己岛屿的生物群系。打开群系菜单后，可选择主世界、下界或末地维度的生物群系进行变更。

## 命令

| 命令 | 说明 |
| :--- | :--- |
| `/is biome` | 打开生物群系菜单 |
| `/is biome <生物群系>` | 直接将岛屿生物群系更改为指定的群系 |
