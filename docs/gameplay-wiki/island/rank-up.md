# 岛屿升级

岛屿升级用于提升岛屿功能等级。玩家可打开升级面板，也可以对某个升级进行提升。

## 命令

| 命令 | 说明 |
| :--- | :--- |
| `/is upgrade` | 打开升级面板 |
| `/is rankup <升级项>` | 升级指定的项目 |

## 升级项

### 刷石机

| 等级 | 价格 | 矿物掉落概率 |
| :--- | :--- | :--- |
| 一级 | 12,000 金币 | 圆石（95%）、煤矿（5%） |
| 二级 | 55,000 金币 | 圆石（95%）、煤矿（8%）、铁矿石（1%） |
| 三级 | 550,000 金币 | 圆石（80%）、煤矿（8%）、红石矿石（6%）、青金石矿石（2%）、铁矿石（2%） |
| 四级（满级） | / | 圆石（95%）、煤矿（10%）、红石矿石（6%）、青金石矿石（4%）、铁矿石（4%）、金矿石（3%）、钻石矿石（1%）、绿宝石矿石（1%） |
