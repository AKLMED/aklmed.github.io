# 岛屿锁定与开放
:::tip

- 当岛屿处于**锁定**状态时，除岛屿成员外的其他玩家将无法进入该岛屿。
- 当岛屿处于**开放**状态时，其他玩家可以自由进入该岛屿（仍需遵守岛屿权限设置）。
- 岛屿锁定/开放状态仅影响非岛屿成员的玩家，岛屿成员不受影响。
- 玩家可通过岛屿菜单或直接输入命令来切换岛屿的锁定状态。

:::
玩家可以通过命令锁定或开放自己的岛屿，控制其他玩家是否可以进入。

## 命令

| 命令 | 说明 |
| :--- | :--- |
| `/is close` | 锁定岛屿，禁止其他玩家进入 |
| `/is open` | 开放岛屿，允许其他玩家进入 |
