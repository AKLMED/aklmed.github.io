# 岛屿银行
:::warning
岛屿成员可以在岛屿银行存入和取出资金，合作成员不能。
:::

岛屿银行用于管理岛屿资金。你可以在这里存入、取出鎏金，并查看交易日志。  

## 命令
| 命令 | 说明 |
|--------|------|
| `/is bank` | 打开岛屿银行 |
| `/is deposit <金额>` | 将您的鎏金存入岛屿银行 |
| `/is withdraw <金额>` | 将岛屿银行内的资金取出 |


## 存款
使用命令`/is deposit <金额>`将您的鎏金存入岛屿银行内

## 提款

使用命令`/is withdraw <金额>`将岛屿银行内的资金取出
