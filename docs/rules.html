苍岚屿玩家协议

欢迎来到 苍岚屿！

当您登录、注册或游玩苍岚屿服务器时，即表示您已阅读、理解并同意遵守本协议。

本协议适用于苍岚屿所有游戏服务器、官网及与服务器相关的其他服务。

苍岚屿运营团队有权根据服务器运营、安全、经济及游戏环境实际情况，对本协议进行更新、补充或修改。协议更新后，将通过官网、游戏内公告或其他合理方式进行通知。

继续使用苍岚屿相关服务，即视为接受更新后的协议。

一、游戏环境​

苍岚屿致力于提供公平、友善、稳定的游戏环境。

请所有玩家共同维护服务器秩序，尊重其他玩家，避免任何破坏游戏体验、服务器稳定性或游戏公平性的行为。

玩家在服务器内进行的所有行为均应遵守：

  • 本玩家协议
  • 服务器公告
  • 游戏内规则
  • 相关功能说明
  • 管理员针对特定事件发布的临时规则

对于本协议未明确列出的恶意行为，管理员仍可以依据公平、公正及维护服务器正常运行的原则进行处理。

二、漏洞与异常反馈​

如果您发现服务器存在漏洞（Bug）、物品复制、经济异常、权限异常或其他可能影响服务器正常运行的问题，请及时向管理员反馈。

我们鼓励​

  • 主动提交漏洞信息
  • 配合管理员复现问题
  • 提供相关截图、录像或日志
  • 协助管理员确认问题
  • 在问题修复前避免继续利用漏洞

严禁​

  • 利用漏洞获利
  • 利用漏洞复制物品、货币或其他资源
  • 恶意传播漏洞利用方式
  • 协助他人利用漏洞
  • 故意隐藏重大漏洞并持续获利
  • 利用漏洞影响服务器经济
  • 利用漏洞导致服务器卡顿、延迟升高或崩溃
  • 利用漏洞影响其他玩家正常游戏

利用服务器漏洞获得的任何货币、物品、岛屿资源、权限、游戏进度或其他收益，管理员均有权进行回收、回滚或修复，并可根据情节给予进一步处罚。

三、公平游戏​

苍岚屿允许合理的游戏辅助功能，但禁止任何破坏游戏平衡、绕过正常玩法或获取不公平收益的行为。

1. 允许的辅助功能​

服务器允许不会影响公平竞争、不会破坏服务器经济、且不会实现无人值守获利的自动化辅助功能。

以下功能原则上允许使用：

  • 自动钓鱼（Auto Fish）
  • 自动收获成熟作物
  • 自动种植
  • 自动补种
  • 自动整理背包
  • 自动补充方块
  • 自动补充工具
  • 快速整理仓库
  • 快捷栏切换
  • 合法的客户端界面优化
  • MiniHUD
  • Inventory Profiles
  • Shulker Box Tooltip
  • Litematica（投影）

以上功能仅限于辅助玩家正常操作。

如果某项功能：

  • 绕过服务器机制
  • 实现无人值守获利
  • 大量自动执行游戏行为
  • 影响服务器经济
  • 影响其他玩家正常游戏
  • 造成异常服务器负载

即使该功能未在禁止列表中明确列出，管理员仍有权认定其违规。

2. 禁止的客户端功能​

禁止使用任何提供不公平优势的客户端、模组、脚本或其他工具，包括但不限于：

  • 飞行
  • 穿墙
  • X-Ray
  • 自动瞄准
  • 加速
  • 无后坐力
  • 自动攻击
  • 自动寻路
  • 自动战斗
  • 透视
  • 其他作弊客户端功能

禁止通过修改客户端、数据包、网络数据或其他技术手段绕过服务器限制。

3. 卡服与影响服务器稳定​

严禁任何导致服务器卡顿、延迟升高、崩溃或影响其他玩家正常游戏的行为，包括但不限于：

  • 大规模生成实体
  • 大规模生成掉落物
  • 高频红石或循环装置
  • 恶意堆积实体
  • 利用游戏机制制造异常负载
  • 利用漏洞制造服务器异常
  • 恶意制造大量区块加载
  • 恶意触发高频插件功能
  • 其他明显影响服务器性能的行为

即使相关行为本身属于 Minecraft 原版机制，如果其使用规模已经明显影响服务器正常运行，管理员仍有权进行限制。

四、经济规则​

苍岚屿的经济系统应建立在正常游戏行为之上。

玩家可以通过正常游戏玩法获得、使用、储存及转移游戏货币。

禁止任何形式的经济作弊，包括：

  • 刷金币
  • 利用漏洞刷货币
  • 利用漏洞刷物品
  • 卡经济
  • 卡交易
  • 利用异常商店机制获利
  • 利用异常任务奖励获利
  • 利用异常插件机制获利
  • 重复领取本不应重复获得的经济收益
  • 利用异常价格无限套利
  • 利用多个账号规避经济限制
  • 明知资金来源异常仍继续使用

管理员有权：

  • 回收异常物品
  • 回收异常货币
  • 回滚异常交易
  • 修复异常经济数据
  • 限制相关经济功能
  • 冻结相关资金
  • 封禁违规账号

五、市场与物价规则​

苍岚屿采用玩家生产、系统商店、NPC、玩家交易及其他经济机制共同构成的市场体系。

玩家可以正常参与市场竞争。

1. 正常市场行为​

以下行为属于正常经济活动：

  • 正常购买物品
  • 正常出售物品
  • 正常囤积资源
  • 根据市场需求调整价格
  • 玩家之间自由议价
  • 正常参与玩家商店
  • 正常参与服务器商店
  • 正常低价收购
  • 正常高价出售

正常的供需变化、价格上涨、价格下降以及个人囤货行为本身不属于违规。

2. 禁止恶意操纵市场​

以下行为可能被认定为恶意操纵市场：

  • 利用漏洞大量制造物品后恶意倾销
  • 利用漏洞大量获取物品并人为制造市场冲击
  • 利用多个账号联合操纵物价
  • 与其他玩家串通人为抬高或压低价格
  • 利用异常交易制造虚假市场价格
  • 利用系统商店反复套利
  • 利用异常机制无限买入、卖出获取差价
  • 明知物品来源异常仍大量参与交易
  • 利用关联账号控制市场价格
  • 通过异常交易行为故意破坏服务器经济平衡

管理员会结合实际情况判断是否属于恶意市场操纵。

单纯的高价出售、低价购买、囤货或正常价格波动，不会自动认定为违规。

六、服务器经济政策​

苍岚屿会根据服务器整体经济情况对经济系统进行调整。

服务器可能调整：

  • 商店购买价格
  • 商店出售价格
  • NPC 交易价格
  • 玩家商店规则
  • 物品产出
  • 物品回收价格
  • 任务奖励
  • 怪物掉落
  • 经济活动限制
  • 资产税率
  • 岛屿银行规则
  • 货币回收机制

当服务器出现严重通货膨胀、严重通货紧缩、物品价格异常、货币数量异常增长、某类资源严重失衡或经济漏洞时，服务器可以调整相关经济机制。

玩家不得以历史价格、历史奖励或历史商店规则作为要求服务器永久维持该规则的依据。

七、资产税与货币回收​

为了维持服务器长期经济稳定，苍岚屿可能使用资产税及其他货币回收机制。

资产税可能分别针对：

  • 玩家个人资金
  • 岛屿银行资金

进行计算。

具体：

  • 起征金额
  • 税率
  • 阶梯区间
  • 结算时间
  • 结算周期
  • 计算方式

以服务器当前配置及官方公告为准。

玩家不得通过临时转移资金、将资金转给其他玩家、使用小号代持、使用关联账号分散资产、使用第三方玩家代持或利用异常交易降低结算资产等方式恶意规避正常税收。

八、玩家之间的资金转移​

玩家之间允许正常进行资金转移。

正常行为包括：

  • 给朋友少量资金
  • 给岛友购买材料
  • 岛屿建设资金分摊
  • 正常奖励队友
  • 正常玩家之间的借款
  • 正常商品交易付款
  • 正常服务费用支付

单笔金额较大并不自动代表违规。

管理员会根据资金来源、金额、频率、交易对象及实际用途综合判断。

九、非法转移财产​

1. 恶意规避资产税​

例如：

玩家 A
↓
持有大量资产
↓
临近税收结算
↓
将大量资金转给 B
↓
税收结算后
↓
B 再将资金转回 A

如果确认主要目的为规避服务器税收，则可能被认定为违规。

2. 利用小号代持​

禁止使用小号、关联账号或第三方账号代持资金，以规避资产税、经济限制、资金冻结、处罚或交易限制。

3. 拆分资金规避限制​

如果玩家故意将一笔大额资金拆分成大量小额交易，以规避服务器设定的经济限制，管理员可以将相关交易合并计算。

例如：

20,000
20,000
20,000
20,000
20,000

如果明显属于规避限制的行为，可以按照总金额进行处理。

4. 第三方代持​

禁止通过：

A → B → C → A

等方式隐藏实际资金所有者、规避处罚或转移异常资金。

十、非法给予玩家经济​

玩家可以正常帮助其他玩家。

但禁止利用经济系统进行异常、大规模或恶意的经济资助。

以下行为可能被认定为非法经济资助：

  • 无正常游戏目的的大额赠予
  • 使用小号向其他玩家转移大量资金
  • 利用异常资金资助其他玩家
  • 为其他玩家规避资产税提供资金
  • 为其他玩家规避经济处罚提供资金
  • 明知资金来源异常仍进行转赠
  • 利用多个账号循环转账
  • 利用他人账号隐藏实际资金所有者
  • 利用赠予行为转移漏洞所得
  • 利用赠予行为规避交易限制

正常经济帮助​

以下行为通常不属于违规：

给朋友 10,000 鎏金
给岛友 50,000 鎏金购买材料
共同建设岛屿进行资金分摊
正常奖励队友
正常借款
正常支付服务费用

服务器不会仅因为玩家之间发生资金转移，就直接认定为非法资助。

十一、异常经济资金​

如果玩家通过 Bug、复制漏洞、异常交易、异常商店机制、异常任务奖励、异常插件行为或其他非正常游戏机制获得资金或资产，相关资金可能被认定为异常经济资产。

无论这些资产之后是否：

  • 转移给其他玩家
  • 存入岛屿银行
  • 用于购买物品
  • 用于出售物品
  • 转移至其他账号
  • 用于市场交易

服务器均有权对异常资金流进行追踪及处理。

十二、资金冻结​

当系统检测到异常经济活动，或者管理员正在调查相关经济行为时，可以对相关账户采取临时资金限制。

1. 转出冻结​

玩家仍可以正常登录、正常游戏、正常购买物品、正常缴纳服务器税收，但暂时无法将被冻结的资金转移给其他玩家。

2. 部分资金冻结​

服务器可以只冻结涉嫌异常的资金，而不是冻结玩家全部资产。

例如：

账户余额：5,000,000

正常资金：4,000,000
异常资金：1,000,000

冻结：1,000,000

3. 全额冻结​

对于严重经济异常、漏洞利用或重大经济调查，管理员可以临时冻结账户全部或大部分资金。

4. 冻结不代表最终认定​

临时冻结主要用于防止异常资金继续扩散、防止异常资金转移、防止异常经济继续影响市场以及为管理员调查提供时间。

调查结束后，服务器可以解除冻结、部分解除冻结、回收异常资金、进行经济处罚或进行账号处罚。

十三、经济处罚​

根据违规程度，管理员可以采取一种或多种处罚。

1. 警告​

适用于：

  • 轻微违规
  • 首次违规
  • 未造成明显经济影响
  • 玩家主动配合处理

2. 回收异常资产​

直接回收通过漏洞、异常机制或违规行为获得的经济收益，包括但不限于：

  • 游戏货币
  • 异常物品
  • 异常资源
  • 异常交易所得

3. 百分比扣款​

对于无法准确确定异常收益，或者存在明显经济违规行为的情况，服务器可以根据违规程度对相关账户资产进行一定比例的扣除。

违规程度可能的扣除比例
一般5%–10%
较严重10%–30%
严重30%–50%
特别严重50% 以上

实际处罚比例由管理员根据获利金额、影响范围、主观恶意、是否重复违规及是否主动配合综合决定。

缴纳处罚金额不能使非法获得的资金合法化。

异常资金仍可能被单独全部回收。

4. 经济功能限制​

服务器可以限制：

  • 玩家转账
  • 玩家商店
  • 玩家交易
  • 岛屿银行
  • 部分商店功能
  • 特定经济功能

5. 岛屿经济处罚​

如果经济违规涉及整个岛屿或多个岛屿成员，服务器可以根据实际情况：

  • 回收异常岛屿资金
  • 回收异常资源
  • 限制岛屿经济功能
  • 暂停岛屿交易
  • 回滚异常经济数据
  • 删除违规获得的资源

6. 封禁​

对于大规模利用经济漏洞、恶意复制货币、大规模非法资金转移、组织多人进行经济作弊、多次规避经济处罚、明知异常资金仍大量传播或恶意破坏服务器经济环境的行为，可以采取临时或永久封禁。

十四、异常经济追踪​

为了维护服务器经济安全，服务器可能记录必要的经济活动信息，包括：

  • 资金转出者
  • 资金接收者
  • 转账金额
  • 转账时间
  • 相关账号
  • 岛屿信息
  • 经济来源
  • 经济去向
  • 异常交易记录
  • 处罚记录

这些信息可能用于：

  • 处理经济纠纷
  • 调查漏洞
  • 追踪异常资金
  • 防止经济作弊
  • 调查非法资金转移
  • 调查资产税规避行为

十五、关联账号与资金关系​

如果多个账号之间存在明显的异常资金流动关系，服务器可以结合实际情况进行调查。

例如：

账号 A
↓
大量资金
↓
账号 B
↓
大量资金
↓
账号 C

如果相关账号同时存在：

  • 规避资产税
  • 规避资金冻结
  • 转移异常资金
  • 利用小号代持
  • 重复领取经济收益

等情况，管理员可以将相关账号及资金流一起进行调查。

正常的家庭成员、朋友、岛屿成员之间的少量正常资金往来，不会仅凭账号之间存在关系就直接认定为违规。

十六、玩家交易​

玩家之间可以自由交易。

但禁止：

  • 欺诈交易
  • 利用他人失误骗取物品
  • 假冒管理员
  • 冒充官方人员
  • 利用插件机制欺骗玩家
  • 利用漏洞进行交易
  • 明知交易物品来源异常仍进行交易

请在确认交易内容无误后再进行确认。

一旦交易完成，除特殊情况外，官方一般不会补偿因玩家个人疏忽造成的损失。

十七、账号安全​

玩家应妥善保管自己的账号。

请勿：

  • 将账号借给他人
  • 向任何人泄露密码
  • 相信所谓“管理员代练”
  • 下载来源不明的客户端
  • 安装未知模组
  • 向他人提供账号验证信息

因账号共享、密码泄露或第三方原因造成的损失，由玩家自行承担。

如果账号被他人使用并产生违规行为，管理员会结合实际情况进行调查。

十八、聊天规范​

请文明交流。

禁止：

  • 人身攻击
  • 恶意辱骂
  • 骚扰他人
  • 刷屏
  • 恶意广告
  • 散布违法内容
  • 发布不适宜内容
  • 恶意挑衅或持续骚扰其他玩家

管理员可根据情节给予警告、禁言、临时封禁或永久封禁。

十九、宣传与广告​

未经允许，禁止：

  • 宣传其他服务器
  • 发布外部群组邀请
  • 发布第三方交易平台
  • 引流至其他社区
  • 发布恶意链接
  • 以任何形式诱导玩家离开苍岚屿参与未经许可的交易

经官方许可的合作宣传除外。

二十、岛屿与资源​

岛屿属于玩家正常游戏数据。

但服务器保留以下权利：

  • 回收违规获得的资源
  • 修复因漏洞产生的数据异常
  • 回滚异常数据
  • 删除严重违规岛屿
  • 修复因服务器异常造成的数据问题
  • 对严重影响服务器环境的岛屿采取限制措施

服务器不会因玩家正常误操作而保证恢复全部损失。

二十一、管理员处理权​

管理员有权根据实际情况采取包括但不限于以下措施：

  • 警告
  • 禁言
  • 临时封禁
  • 永久封禁
  • 删除违规物品
  • 回收异常经济收益
  • 百分比扣款
  • 冻结资金
  • 限制资金转出
  • 限制经济功能
  • 回滚数据
  • 回滚异常交易
  • 删除违规岛屿
  • 限制实体生成
  • 限制红石设备
  • 限制其他可能影响服务器稳定性的功能

对于未明确列出的恶意行为，管理员仍有权依据公平、公正及维护服务器正常运行的原则进行处理。

二十二、处罚说明​

违规行为可能导致：

  • 聊天限制
  • 游戏限制
  • 经济功能限制
  • 资金冻结
  • 财产回收
  • 百分比扣款
  • 岛屿回滚
  • 岛屿删除
  • 临时封禁
  • 永久封禁

处罚将综合考虑：

  • 违规行为性质
  • 获利金额
  • 影响范围
  • 影响时间
  • 是否主动利用漏洞
  • 是否主动传播
  • 是否主动配合处理
  • 是否属于重复违规
  • 是否存在规避处罚行为
  • 是否对服务器经济造成明显影响

二十三、处罚与异常资产处理原则​

服务器在处理经济违规时，原则上会优先区分：

正常资产
异常资产
违规所得

对于可以明确追踪的异常资产，服务器可以优先回收异常资产。

对于无法准确区分异常所得，且玩家存在明显恶意违规行为的情况，服务器可以根据实际影响采取：

  • 百分比扣款
  • 资金冻结
  • 经济功能限制
  • 岛屿经济处罚
  • 账号处罚

等措施。

服务器不会因为单纯存在大额余额、正常赠予或正常交易，就自动认定玩家违规。

二十四、玩家申诉​

如果玩家认为自己遭受了错误的经济处罚、资金冻结或账号处罚，可以通过官方渠道进行申诉。

申诉时建议提供：

  • 游戏 ID
  • 相关时间
  • 事件经过
  • 相关截图
  • 交易记录
  • 其他可以证明情况的信息

管理员会根据服务器日志、经济记录及实际情况进行核查。

玩家不得通过刷屏、骚扰管理员、恶意威胁或公开散布未经证实的信息等方式要求解除处罚。

二十五、协议修改​

苍岚屿保留对本协议进行更新、补充及修改的权利。

协议可能因以下情况进行调整：

  • 游戏版本更新
  • 插件更新
  • 服务器功能调整
  • 经济系统调整
  • 安全问题
  • 漏洞修复
  • 社区管理需求
  • 法律法规或平台规则变化

更新后的协议将在官网或游戏内公告后生效。

继续游玩服务器即视为接受最新协议。

二十六、最终解释权​

本协议最终解释权归 苍岚屿服务器运营团队 所有。

苍岚屿运营团队将尽可能根据公开规则进行处理，并尽量保持处罚的一致性与合理性。

感谢您共同维护公平、健康、稳定、友善的游戏环境。
